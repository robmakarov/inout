Open this app over HTTP

Browsers treat file:// as a restricted origin. Screen capture, recording, and some loads fail with errors like “Unsafe attempt to load URL … from frame”.

If the address bar already shows http:// but you still see a file:// error, you are not using the page from the dev server: close the tab that opened this file from disk, run npm start, then open only the URL it prints (use normal Chrome, not an editor preview).

  1. Open a terminal in this project folder.
  2. Run npm start
  3. Open http://127.0.0.1:8765/ in the browser.
