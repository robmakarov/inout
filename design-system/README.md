# Design system

**This folder is part of the project's documentation.** In this project, **documentation = all `.md` and `.txt` files** (root README, TODO.txt, documentation/, design-system/). When you change code or any of these files, update the others in the same change set. See **.cursor/rules/docs.mdc**.

You say what to change; assistant updates **code + these files**.

- animations.md — tokens, keyframes, DnD
- components.md — IDs, classes, states
- colors.md — tokens + values
- text.md — fonts, copy
- modes.md — select, edit, DnD, view, modals, scroll, toast
- dnd.md — feed/table/graph DnD abstraction
