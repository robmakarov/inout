## The formulation — quote it
On macOS, Chrome's screen picker takes the share (the sharing indicator lights) but `getDisplayMedia` NEVER resolves and never rejects — the page never receives a track, so no page code can release or retry the claim. The stuck state lives in Chrome's browser process: it survives page refresh, closing the tab, opening a new tab, sometimes a fresh Chrome launch. It clears on ⌘Q, and — cheaper, found by Robert 2026-08-30 — on resetting the SITE's permissions inside Chrome, which is why the state is believed per-site.
